# Prototype maps

`EnglishChannel-1944-OfficialStyle-v1.png` is an AI-assisted prototype redraw.

- Geography/framing reference: `Assets/Art/map.png`
- Visual-style reference: the official *Strike Witches: ROAD to BERLIN* October
  1945 Europe map (kept outside the distributable prototype asset set)
- Intended use: internal prototype base map beneath runtime labels, units, paths,
  detection ranges, combat regions, and other tactical overlays

The image is intentionally unlabeled so names can be localized and rendered in
Unity. Its coastlines and transport network are illustrative rather than GIS- or
survey-accurate. Base Command now supplies a separate gameplay coordinate
contract of `560 x 315 km`, with one simulation unit equal to one kilometre;
that contract controls gameplay distance and does not imply pixel-level GIS
accuracy.

This derivative is prototype-only and must be reviewed or replaced before any
public demo or release.
